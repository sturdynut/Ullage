Ullage in the menu bar

Ullage is the empty space left in a cask — the headroom above the liquid. This is what the app puts in your menu bar: how full the context window of your most recently active Claude Code session is, updating within about two seconds of a turn finishing.

Every string here comes from the code that exists: the title from MenuBarFormatter, the rows from MenuContent. The greyed rows are greyed for a real reason — plain Text in a SwiftUI menu renders as a disabled item; only the three buttons at the bottom are clickable.

Occupancy is input + cache_creation + cache_read over the model's window. All three are prompt tokens; input_tokens alone is only the uncached remainder, which on a warm session undercounts by an order of magnitude. Percentages are floored, so 99.6% never shows as full.

Table view · 48 rows

These are rows out of the database, not drawn numbers: a session was ingested through the real parser, and the chart reads ts, context_tokens and context_delta straight from the call table. The cliff at 10:26 is why the event table exists — occupancy falls from 87% to 14% between two adjacent turns, and without the marker that reads as a bug rather than as the moment the session forgot. The line breaks there because context_delta is NULL by design across a compaction.

Not shipped. Charts are an explicit non-goal for v1 — the menu bar renders one number. Everything needed to draw this is already in the schema, so it stays a later addition rather than a rewrite.

How much of this is real

Verified by running it

Parsing, the token formula, the SQLite store, idempotent re-ingest, partial-line handling, live tailing, and every display rule above — 56 passing tests plus hands-on runs.

Never compiled

The FSEvents watcher and the SwiftUI views are macOS-only and were written on Linux. This page is an HTML rendering of that code's intent, not a photograph of it running.

Still to confirm

Field names came from the plan, not from your disk. Run scripts/recon.sh and compare /context in a live session before trusting a single row.
